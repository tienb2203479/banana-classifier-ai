# PROMPT 2 - TAO KHUNG WEB PHAN LOAI CHUOI

Ban la Fullstack Engineer senior.
Hay tao khung web app phan loai chuoi chay tot tren ca PC va mobile.

Muc tieu san pham:
- Nguoi dung upload anh hoac chup anh bang camera dien thoai.
- Web goi API du doan va hien thi:
  1) loai chuoi
  2) dang
  3) trang thai
  4) confidence tung dau ra
- UI gon, ro, toc do nhanh.

Yeu cau frontend:
1. Responsive mobile-first.
2. Co trang chinh upload/chup anh va trang lich su du doan.
3. Hien thi loading, loi, retry ro rang.
4. Anh preview truoc khi gui.
5. Hien thi canh bao khi confidence thap.

Yeu cau backend:
1. API health check.
2. API predict nhan anh va tra JSON chuan.
3. Logging request/response time.
4. Validate file upload, gioi han dung luong.
5. Chuan bi san cho tich hop model that.

Yeu cau kien truc:
1. Tach frontend va backend.
2. Co file moi truong cau hinh.
3. Co Docker hoac script chay local nhanh.
4. Co README chay trong 5 phut.

Dau ra mong muon:
1. Cau truc project web day du.
2. Cac endpoint API va schema du lieu.
3. Lenh chay local.
4. Checklist test tren PC va mobile.
5. Danh sach buoc tich hop model sau do.

Format tra loi:
1. Viec da lam
2. File tao/sua
3. Lenh chay
4. Cach test
5. Next step
